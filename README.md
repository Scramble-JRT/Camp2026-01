# ねるな!!大石 — 居眠り検知アプリ

USBカメラで顔を見て、目を閉じ続けている(居眠りしている)ことを検知し、寝ている時間が長くなるほど強い警告レベルを出す Tkinter アプリです。

## 動かし方

1. `setup.bat` を実行する(仮想環境 `.venv` の作成とパッケージのインストール)
2. `run.bat` を実行する(または `.venv\Scripts\python face_recognition_sample.py`)

初回起動時に学習済みモデル(ONNX / MediaPipe)を `models/` に自動ダウンロードします。

必要なもの: Windows、Python 3.9 以上、USBカメラ。
パッケージは `requirements.txt`(`opencv-python` / `numpy` / `mediapipe`)。画面は標準の Tkinter なので追加インストールは不要です。

## 画面の流れ

| 順番 | 画面 | 内容 |
|---|---|---|
| UI1 | タイトル | 「起きろ!! 大石!!」と `[PRESS ENTER]`。**Enter キーを押すと次へ進む** |
| UI2 | ローディング | 8個の点が時計回りに回るスピナー。**3秒間**表示して自動で次へ進む |
| UI3 | メイン | カメラ映像と睡眠検知の画面 |

- 全画面で起動する。**F11** で全画面の切り替え、**Esc** で全画面の解除ができる(メイン画面は下の「全画面」ボタンでも可)。
- 画面のレイアウトは 1920×1080 を基準に、ウィンドウの大きさへ縦横比を保って拡大縮小する(余りは中央寄せ)。
- 文字はピクセル指定のフォント(Meiryo)で、Windows の表示スケールに左右されない。帯の中に収まらない長い文字は自動で小さくする。

デザイン元の画像は `UI1.png`(タイトル)、`UI2.png`(ローディング)、`UI3.png`(メイン)。

## メイン画面の構成(UI3)

- **カメラ映像**(左上): 顔の枠、傾き、目のつぶり度合いを重ねて表示
- **見出し**(右上): 手書き風の「起きろ!! 大石!!」
- **現在のレベル**(赤い帯)と **Next...**(次のレベル)
- **進み具合のバー**: 緑が、今のレベルで経過した時間。下に「残り◯秒(10中)」
- **睡眠時間**(右下): 睡眠と判定されてからの経過秒数
- **状態**(左下): 「睡眠」「通常」のうち、今の状態が大きく色付きで出る
- **レベル一覧**: 6段階を並べ、今のレベルだけ赤くする
- **画面下のボタン**: 「画面を保存」(`capture_result.jpg` に保存)、「全画面 (F11)」、「終了」

## 検知の仕組み

| 項目 | 使うもの |
|---|---|
| 顔の検出・傾き | OpenCV YuNet |
| 顔の識別(誰か) | OpenCV SFace(`known_faces/` の写真と照合) |
| 目のつぶり度合い | MediaPipe Face Landmarker(0〜100%) |

- **横向き対応**: 画像を 0度・時計回り90度・反時計回り90度の3方向で検出し、座標を元に戻す。横向き(90度)の顔でも検出・識別・目の判定ができる。上下逆さまは対象外。
- **目を閉じている判定**: 左右の目のつぶり度合いの平均が **40%以上**。
- **顔の識別**: `known_faces/` の写真(ファイル名 = 名前)を起動時に読み込んで照合する。写真がなければ名前は出さず検出のみ。画面からの顔の登録機能はない。
- 複数の顔が映っている場合、目を閉じている顔が1つでもあれば「閉じている」とみなす。

## 睡眠の判定とレベル

1. 目を閉じ始めた時刻から数え、**2秒以上**閉じ続けたら「睡眠」とみなす(まばたき対策)。睡眠時間は目を閉じ始めた時点から数える。
2. 目が開いても、**2秒以内**にまた閉じれば睡眠は続いているとみなす。目が開いて2秒たつと「通常」に戻り、睡眠時間とレベルはリセットされる。
3. 睡眠が続くと、**10秒ごと**にレベルが1つ上がる。Level6 で止まる。

| レベル | 名前 | 動作 |
|---|---|---|
| Level1 | 警告 | 警告音 |
| Level2 | こちょこちょ | こちょこちょ |
| Level3 | つんつん | つんつん |
| Level4 | 最終警告 | 最終警告 |
| Level5 | つねる | つねる |
| Level6 | つねってひねる | つねってひねる |

通常時は赤い帯が「待機中」(灰色)になり、Next は Level1 を示す。Level6 では Next が「なし」、下の表示が「最終レベル」になる。

## 音声

そのレベルに**上がった瞬間に1回**鳴らす(前の再生が終わっていなければ重ねない)。

| レベル | 音声ファイル |
|---|---|
| Level1 | `起きてください.mp4` |
| Level4 | `起きろ大石.mp4` |

Windows 標準の MediaPlayer を PowerShell 経由で使うので、追加ライブラリは不要。音声ファイルは `face_recognition_sample.py` と同じフォルダに置く。ファイルがなければメッセージを出して無音で続ける。

## 設定値

`face_recognition_sample.py` の先頭付近の定数で変えられる。

| 定数 | 既定値 | 意味 |
|---|---|---|
| `CAMERA_ID` | 1 | カメラの番号。USBカメラは通常 1、PC内蔵は 0 |
| `EYE_CLOSED_THRESHOLD` | 40 | 目のつぶり度合いがこの%以上で「閉じている」(小さいほど判定が広い) |
| `SLEEP_CONFIRM_SEC` | 2.0 | 目を閉じ続けて「睡眠」とみなすまでの秒数 |
| `WAKE_GRACE_SEC` | 2.0 | 目が開いても睡眠を続けているとみなす秒数 |
| `LEVEL_SEC` | 10 | 次のレベルに上がるまでの秒数 |
| `LEVELS` | 6段階 | レベルの名前と動作 |
| `LEVEL_SOUNDS` | Level1, Level4 | レベルごとの音声(キーは 0 始まり) |
| `Splash.LOADING_MS` | 3000 | ローディング画面の表示時間(ミリ秒) |
